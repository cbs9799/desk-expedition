# 책상 원정대 경쟁작 조사

**조사 기준: 2026년 11월 24일.** 최근 1년은 **2025-11-24~2026-11-24**로 잡았습니다.

핵심 결론은 **“작은 RPG”보다 “작업을 방해하지 않는 RPG”가 차별화의 중심**이라는 것입니다. 전투·수집의 깊이를 늘린 경쟁작에서도 인벤토리 정리, 늦은 자동화 해금, 성장 정체, 창·모니터 문제가 반복됩니다.

- **직접 경쟁:** Desktop Heroes, Traymon World, Deskrawl, TBH, DPS.
- **업무 동반 경험의 기준점:** Rusty’s Retirement, Bongo Cat, Tiny Pasture.
- **성장·전략 구조를 참고할 인접작:** Slotbound, Idle Champions.
- **주의:** Traymon World는 조사일 현재 **출시 전**입니다. Slotbound는 **하단 상주형 게임이 아닙니다.**

## 조사 기준과 한계

- 가격은 **미국 Steam 정상가**, 할인가는 별도로 구분했습니다.
- 리뷰 수·긍정률은 가능한 한 **전체 언어·전체 구매 경로**로 통일했습니다. 무료 키·외부 취득 리뷰를 제외하는 상점 기본 점수와 다를 수 있습니다.
- 커뮤니티 평가는 여러 리뷰·토론에서 재확인된 주제를 중심으로 정리했습니다. 전수 분석이나 빈도 통계는 아닙니다.
- 기능은 **공식 설명**, **사용자 제보**, **미확인**을 구분했습니다. 직접 실행한 CPU·GPU·배터리 벤치마크는 없습니다.
- 아래의 “최신 패치”는 **확인한 공개 공지 기준**입니다. 빌드 파일 변경과 기능 업데이트, 향후 로드맵은 구분했습니다.

# 1. Desktop Heroes

**가장 직접적인 비교작입니다.** macOS를 지원하며, 하단 판타지 RPG에 작업 방해를 줄이는 기능을 결합했습니다.

### 핵심 루프
자동 전투 → 골드·장비·재료 → 장비 교체·스탯 강화·포션 제작 → 보스·지역 해금. 현재 구조는 네 영웅 동시 출전이라기보다 **활성 영웅과 사이드킥 조합**이며, Fairy가 회복·판매 등 자동화를 담당합니다.

### 반복되는 칭찬과 불만
- **칭찬:** 작은 픽셀 모험을 업무와 병행하는 분위기, 개발자의 대응, 화면 점유 조절.
- **불만:** 가방 포화와 장비 정리 때문에 자주 확인해야 함, 후반 성장 정체와 콘텐츠 깊이 부족.
- 특히 **2026년 10월 리뷰에도 “몇 분마다 가방을 확인한다”는 불만**이 있어 초기 출시 문제로만 보기 어렵습니다.
- 반면 죽으면 진행이 멈추거나 동료 성장이 부족하다는 초기 불만은 자동 부활·사이드킥 패치 전후를 구분해야 합니다.

### 최근 업데이트 방향
확인된 최신 공지는 **2026-03-24 v3.0.5**입니다.
- 열등 장비 자동 판매와 공격적 판매 옵션.
- 필수 이벤트가 생략되어 진행이 막히는 문제 수정.
- 직전 3.0에서는 스토리 캠페인·퀘스트·NPC·상위 보스 확대.

즉, **관리 자동화 개선 + 후반 목표 확장** 방향입니다. 이후 업데이트가 전혀 없었다고 단정할 근거는 없습니다.

### 데스크톱 특화 기능
- <citation refs="G6nDxNxLlf8eMYDTz9nBU">Virtual Mode는 뒤쪽 앱으로 클릭을 통과시키고, Protect Mode는 화면 캡처·공유에서 게임을 숨기는 기능으로 개발자가 소개합니다.</citation> 다만 모든 macOS·회의 앱 조합에서의 작동은 미검증입니다.
- 줌·배경 표시 조절, VFX 끄기 지원.
- 보조 모니터 사용 후기는 있지만 **혼합 DPI·모니터 선택·독점 전체화면 공존은 미확인**.
- 장시간 지연·메모리 증가 제보가 있으나 제한된 사례로, 모든 환경의 문제라고 일반화할 수 없습니다.
- **Windows·macOS·Linux 공식 지원.** Apple Silicon 네이티브 여부는 별도 확인이 필요합니다.

# 2. Traymon World: Taskbar Monster RPG

**macOS 하단 수집 RPG라는 점에서 중요한 출시 예정 경쟁작입니다.** 본편 출시 예정은 **2026-11-26 10:00 KST**입니다.

### 핵심 루프
알 부화·몬스터 수집 → 3마리 편성 → 속성·역할·특성·Charm 시너지 → 자동 탐험·전투 → 성장·고난도·추가 수집.

공식 공개 사양은 본편 **80종 몬스터**, 지역·보스, 계정 성장, 특성 선택, 장터 거래입니다. 아직 출시 빌드를 검증한 것은 아닙니다.

### 가격·수익모델
무료 본편에 다음 유료 상품을 결합합니다.
- 부화 슬롯·창고·장터 등록 슬롯을 늘리는 **Convenience Pack**.
- 알·Charm·경험치 아이템을 주는 **Tamer Set**.
- 전용 몬스터가 포함된 Supporter Pack, OST.
- 몬스터·장비·알의 Steam 장터 거래.

**단순 코스메틱 F2P가 아닙니다.** 조사일에는 개별 USD 가격이 공개되지 않았습니다.

### 이용자 반응
- **본편 리뷰 없음. 반복되는 칭찬·불만을 판단할 단계가 아닙니다.**
- 데모에는 스킬 설명, 부화·특성 RNG, 성장 속도에 대한 불만이 있으나 독립 표본이 부족합니다.
- 제3자 사이트의 데모 7건·57%는 소표본·과거 보관값이므로 **본편 평점으로 사용하지 않았습니다.**

### 최근 개발 방향
- **10/14 데모:** 부화시간 단축, 몬스터 스킬 다양화·설명 개선, 배율 설정, 이름 지정, 창고 정렬.
- **11/23 본편 안내:** 수집·계정 성장·거래·UI 확대.
- 데모는 11/23 배포 종료. 본편으로 세이브가 이전되지 않습니다.

### 데스크톱 특화 기능
- **Windows·macOS 공식 지원**, Mac 최소 사양은 macOS 13.3·M1 상당·RAM 4GB로 표기.
- 표시 배율 설정은 공식 확인.
- **멀티모니터·혼합 DPI·클릭 통과·전체화면 자동 숨김·장시간 성능은 미확인**입니다.

# 3. Rusty’s Retirement

**“작업 옆에서 돌아가는 게임”의 사용 경험을 가장 먼저 비교할 작품입니다.**

### 핵심 루프
작물 재배 → 로봇의 물주기·수확 → 바이오연료 생산·판매 → 토지·작물·로봇 확장 → 자동화와 배치 개선.

### 반복되는 칭찬과 불만
- **칭찬:** 귀여운 픽셀 농장, 업무·논문·영상 시청과의 병행, 짧게 확인해도 보상이 있는 자동화.
- **불만:** 초반에는 수동 구매·업그레이드가 산만함, 해금 후 장기 목표가 약함, 더 큰 창이나 전체화면을 원함.
- “일을 못 하겠다”는 농담형 추천 리뷰와 실제 주의 분산 불만은 구분했습니다.
- 후반 콘텐츠 부족 평가는 이후 콜라보 맵 추가 전 경험도 섞여 있습니다.

### 최근 업데이트 방향
확인한 공식 피드의 최신 공지는 **2025-10-06 Build 1.1.6**이며, 2026년 신규 기능 공지는 확인하지 못했습니다.
- 가을 맵·버섯·할로윈 장식·베리 추가 및 밸런스 조정.
- Balatro 콜라보의 포커 보상, Vampire Survivors 콜라보의 박쥐·마늘 등.

단순 스킨보다 **새 맵에 기존 루프를 변주하는 규칙**을 붙이는 방향입니다.

### 데스크톱 특화 기능
- **모니터 전환, 가로·세로 농장, 줌·위치 조절, Always on top 선택**.
- **Focus Mode:** 생산을 느리게 해 확인 빈도를 낮춤.
- 일반 전체화면 모드 요구가 반복되지만 추가 구현 증거는 확인하지 못했습니다.
- 과거 다중 화면 주사율·다른 앱 끊김 제보와 저부하 사용 후기가 공존합니다. 현행 성능을 일괄 판단할 수 없습니다.
- **macOS 공식 지원.** Mac에서는 Dock·메뉴바·모니터 선택 관련 요청이 있었습니다.
- 종료 중 진행은 지원하지 않는다는 커뮤니티 답변이 있습니다. 오프라인 진행형과는 구분됩니다.

# 4. Bongo Cat

**RPG의 깊이보다 “계속 켜둘 이유”를 배우기 좋은 작품입니다.**

### 핵심 루프
평소 키보드·마우스 입력 → 고양이 반응·카운터 → 아이템 획득 → 모자·스킨·이모트·UI 수집 → 꾸미기와 함께 표시.

별도 노동을 요구하기보다 **원래 하던 행동을 수집 보상으로 바꿉니다.**

### 반복되는 칭찬과 불만
- **칭찬:** 귀엽고 부담 없는 공부·업무 동반자, 입력 반응, 의상 수집과 계절 콘텐츠.
- **불만:** Steam 플레이시간·연말 결산을 점령함, 과도한 입력 업적 부담, 투명 오버레이의 검은 박스.
- 500만 입력 업적에 대한 반발에는 개발자가 업적 제거와 보상 조건 조정으로 대응했습니다. 현재 미해결 문제로 보기는 어렵습니다.
- 자원 사용 불만도 있으나 커뮤니티 개별 수치를 표준 성능으로 사용하지 않았습니다.

### 최근 업데이트 방향
- **2026년 9월 Paw Pass**, 10월 UI 테마, 11월 봉고·가을 콘텐츠.
- 최신 기능 공지는 **11/01 UTC**: 봉고 슬롯, 계절 아이템·UI, 배치 조절, UI 애니메이션 끄기, 백그라운드 idle 성능·시작 위치·투명도 복구 개선.
- 11/19 빌드 변경은 있지만 설명이 없어 기능을 추정하지 않았습니다.

### 데스크톱 특화 기능
- 모니터 선택, 위치·크기·카운터 조절, Gaming Mode.
- 과거의 “다른 화면으로 드래그” 안내보다 **F8·설정의 모니터 선택**이 최신 사용 보고에 부합합니다.
- 타 앱의 독점 전체화면 위 표시나 자동 숨김은 현행 보장 미확인.
- **현재 macOS 공식 지원.** 2025년 초 미지원 정보는 오래된 상태입니다.

**수익모델:** 무료 + 코스메틱·후원 상품·Steam 장터 + 무료/프리미엄 Paw Pass. 패스는 과거 보상 해금과 보상 비만료를 내세워 기간 압박을 낮춥니다.

# 5. Slotbound

**하단 상주형 경쟁작이 아니라, 자동전투·수집·확률 통제 설계의 인접 참고작입니다.**

### 핵심 루프
<citation refs="hMkLQbQmJyv1hmzC9301r">3×3 슬롯으로 병력 소환 → 배치·흡수·전직 → 아이템·각인·코어 시너지 → 자동 전투 → 영구 성장 → 다음 런.</citation>

전투는 자동이지만 회전·흡수·상점 선택이 반복되는 **적극적 런 기반 로그라이트**입니다.

### 반복되는 칭찬과 불만
- **칭찬:** “한 판 더”의 중독성, 가격 대비 재미, 희귀 병력·조합 실험, 예상보다 깊은 전략.
- **불만:** RNG가 결과를 과하게 지배함, 초반 메타 재화 노가다와 스탯 벽, 조작·설명·겹친 병력의 가독성.
- 초기 저장·속도 관련 불만을 그대로 현행 문제로 쓰면 안 됩니다. 최신 버전은 저장 런과 Endless 3배속을 명시합니다.

### 최근 업데이트 방향
최신 확인 패치는 **11/22 v1.0.3**입니다.
- 희귀 병력 접근성과 실패 런 보상 개선.
- 일부 확률 풀·퀘스트 재추첨 조정.
- 저등급 우선 흡수·저장 덮어쓰기 경고·단축키 표시.
- 전투·상점 구매 끊김, 트랙패드 조작 오류 개선.

**확률 좌절을 줄이고, 반복 런의 조작 비용을 낮추는 방향**입니다.

# 이 장르에서 장기 리텐션을 만드는 요소

아래는 리뷰·운영 패턴에서 도출한 **제품 설계 가설**입니다. 공개 D30·D90 코호트 데이터로 인과관계를 입증한 결론은 아닙니다.

## 1. 접속을 유지시키는 것보다 “마음 놓고 안 봐도 되는 것”

가장 반복되는 실패는 **방치형을 약속했는데 관리형으로 작동하는 것**입니다.

- Desktop Heroes: 가방 정리.
- Tiny Pasture: 먹이·수집·건강 관리.
- DPS: 상자 제한·개봉·합성.
- Rusty: 초반 수동 확장.

**책상 원정대 제안:** 자동 판매·분해·장비 필터를 초기에 제공하고, 인벤토리 포화나 사망이 업무 중 성장을 멈추게 하지 않는 편이 좋습니다. 자동화를 후반 보상이나 유료 불편 해소로만 남기면 제품의 핵심 약속과 충돌합니다.

## 2. 조작 빈도와 전략 깊이를 분리하기

Idle Champions의 편성, Traymon의 3마리 시너지, Deskrawl의 장비·미니언은 확인할 이유를 만듭니다. 문제는 그 선택 앞뒤에 반복 정리가 붙는 경우입니다.

**좋은 구조:**  
**작업 중에는 자동 실행 → 쉬는 시간에 한 번의 의미 있는 빌드 변경 → 다음 확인 때 결과 관찰.**

클릭 횟수보다 조합의 결과가 달라져야 합니다.

## 3. 숫자뿐 아니라 화면에서 성장해야 함

작게 켜놓는 게임에서는 수치 창보다 **보이는 변화**가 강합니다.

- 새 동료·펫·외형.
- 전투 방식과 스킬 애니메이션 변화.
- 마을·야영지·수레의 확장.
- 계절 장식과 개별 캐릭터의 애착 요소.

Bongo Cat은 전략이 얕아도 이 축이 강합니다. 반대로 숫자만 커지면 후반 목표가 쉽게 파밍 시간으로 환원됩니다.

## 4. 희귀 수집에는 통제감이 필요함

Slotbound·Tiny Pasture·Deskrawl·TBH에서 **희귀 보상의 기쁨과 RNG 좌절**이 함께 나타납니다.

**책상 원정대 제안:** 확정 제작·누적 천장·중복 교환·선택 가능한 목표 파밍을 제공하십시오. 희귀 보상이 없어도 다음 세션에 가까워졌다는 증거가 남아야 합니다.

## 5. 새 콘텐츠는 양보다 “기존 루프를 바꾸는 규칙”

Rusty의 콜라보 맵은 기존 자산에 다른 규칙을 붙입니다. Idle Champions는 기존 챔피언의 리밸런싱과 변형 도전으로 오래된 수집물을 다시 쓰게 합니다.

**추천:** 신규 지역 숫자만 늘리기보다 역할이 바뀌는 원정 조건, 특정 조합이 유리한 주간 도전, 기존 동료 재발견을 우선하는 편이 유지 비용 대비 유리합니다.

## 6. macOS에서는 창 관리·안정성이 곧 콘텐츠

이번 조사에서 다수 게임은 “지원 OS”보다 **실제 업무 환경과의 공존**이 덜 검증돼 있었습니다.

책상 원정대의 우선 검증 항목은 다음입니다.

- 모니터별 위치·크기 저장, 서로 다른 배율·해상도.
- 외부 모니터 연결 해제·재연결, 잠자기·깨우기.
- Spaces·Mission Control·Stage Manager·전체화면 앱 전환.
- Dock 자동 숨김, 클릭 통과, 포커스 탈취 방지.
- 화면 공유 때 숨김 선택.
- 백그라운드 저FPS·효과 제한·저전력 모드.
- 장시간 메모리 증가, 세이브·오프라인 보상 복구.

**“작아서 가볍다” 대신 CPU·메모리·전력의 실측값을 공개하는 것 자체가 차별화**가 될 수 있습니다.

## 7. 장터·편의 과금은 체류와 신뢰를 함께 봐야 함

TBH·Deskrawl·DPS·Traymon은 장터나 편의·성장 판매를 활용합니다. 수집 동기는 커지지만, 파밍 공정성·보관 제한·계정 신뢰 문제가 게임 경험을 압도할 위험도 있습니다.

책상 원정대에는 우선 **유료 본편 + 외형·테마 확장**을 검토할 만합니다. 이는 확정 최적 모델이라는 뜻이 아니라, “작업을 방해하지 않는다”는 약속을 지키기 쉬운 구조라는 판단입니다.

## 책상 원정대의 권장 포지션

> **일하는 동안에는 손이 안 가고, 쉬는 시간에는 편성을 바꿀 맛이 있으며, macOS 작업 환경에서는 존재를 잊어도 안전한 픽셀 원정대.**

성과 지표도 단순 실행시간보다 **주간 재실행률, 실제 빌드 변경률, 자동화 이후 잔존율, 작업 중 강제 개입 횟수, 자원 사용량, 장시간 오류율**을 함께 보는 것이 좋습니다. 상주형 게임에서는 오래 켜져 있다는 사실과 오래 좋아한다는 사실이 같지 않습니다.
